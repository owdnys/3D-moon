# 地月系统 · Earth & Moon

一个纯静态的 3D 地月系统网页：地球与月球同处一片星空，点击星球或底部按钮即可在两者之间平滑切换视角。

![地球](https://img.shields.io/badge/Earth-NASA%20Blue%20Marble-3b82f6) ![月球](https://img.shields.io/badge/Moon-LROC%204K-9ca3af)

## 功能

- **双焦点切换**：点击地球 / 月球（或工具栏「地球」「月球」按钮），相机平滑飞到目标星球，半径自动适配。
- **真实比例**：月球半径为地球的 0.2726 倍（3474.8 / 12742 km）；地月距离按视觉压缩显示，中线示意两者方位。
- **地球**：日照贴图 + 夜景灯光 + 独立云层 + 海面镜面高光（无大气辉光），昼夜分界随太阳方位实时变化。
- **月球**：NASA LROC 4K 彩色影像 + LOLA 高程（凹凸/位移），可放大到环形山近景；8 个月面地名标注（静海、雨海、第谷环形山、阿波罗 11 号着陆点等）随自转跟随、转到背面自动隐藏。
- **按焦点变化的工具栏**：只有聚焦月球时才出现「标注」「月相」两个按钮，在地球视角下工具栏更简洁。
- **月相**：工具栏「月相」循环切换月球的光照方位（34° → 满月 → 45° → 90° → 180° 新月），只影响月球；地球使用固定的受光角度，观察月相时地球不会一起变暗。
- **交互**：拖动旋转（带惯性）、滚轮/双指缩放、双击复位、点击星球切换焦点；键盘 `E`/`L` 切焦点、空格自转、`R` 重置、`F` 全屏、方向键旋转、`+`/`-` 缩放。
- **移动端适配**：≤720px 自动切换为图标工具栏、竖屏取景、安全区留白，支持触摸拖动与双指缩放。

## 运行

不需要服务器、不需要联网、不需要安装依赖：

```
双击 index.html（推荐 Chrome / Edge）
```

所有贴图都以 base64 内嵌在 JS 中，因此 `file://` 直接打开即可运行。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 页面本体：界面、交互、WebGL 渲染逻辑 |
| `three.min.js` | three.js r128（UMD） |
| `earth-assets.js` | 地球贴图：日照 / 夜景 / 云层 / 海面高光（base64） |
| `moon-assets.js` | 月球贴图：LROC 4K 彩色影像 + LOLA 高程（base64） |

## 数据来源

- 地球贴图：源自 [3D-earth](https://github.com/owdnys/3D-earth) 项目（NASA Blue Marble 系素材）。
- 月球影像与高程：[NASA SVS · CGI Moon Kit](https://svs.gsfc.nasa.gov/4720)（LROC WAC 彩色图 + LOLA 位移图，公有领域）。
